# Accessibility Handoff Review

A Figma agent skill for a preliminary design-stage review of potential accessibility concerns before engineering handoff. It examines labels, visual hierarchy, contrast concerns, pointer and touch targets, and interaction states, then prepares evidence, suggested fixes, and a human-review handoff record.

## Use it in Figma

Upload `SKILL.md` as an existing custom skill, then invoke `/leo-accessibility-handoff-review` in a Figma agent or Figma Make chat.

This is a design-stage review, not an accessibility audit or release approval.
